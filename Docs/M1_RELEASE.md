# M1 phát hành — tài khoản Google, bot và admin (2026-09-23)

M1 này theo `KE_HOACH_DUA_PROMPT_CHIEN_VAO_SU_DUNG.md`, khác M1 engine lịch sử. Backend phát hành là Node + SQLite. Chủ dự án xác nhận dữ liệu D1/VPS là dữ liệu thử không cần chuyển; migration vẫn giữ dữ liệu cũ trên bản sao. Theo ủy quyền bổ sung, API đã phát hành lên VPS và web lên Vercel; chưa merge hoặc tắt Worker.

## Tệp và hợp đồng

- `apps/api/node-migrations/0003_google_admin.sql`, `apps/api/src/node.mjs`: thêm Google `sub` duy nhất, email hiển thị, `role=player|admin`, `disabled_at`, `admin_audit`. Node chạy migration một lần trong transaction, đặt `PRAGMA user_version=3`. User cũ không có Google link vẫn trong DB; không tự ghép vì trùng email.
- `apps/api/src/google-auth.mjs`, `apps/api/src/index.mjs`: `POST /api/auth/google` nhận `{credential}`, xác minh chữ ký/audience/issuer/hạn dùng, tạo hoặc tìm user theo `sub`, trả `{user}` và cookie HttpOnly 7 ngày. Token sai `401`, account khóa `403`. `GET /api/auth/google-config` trả Client ID; `GET /api/auth/me` trả user/role hoặc `401`; `POST /api/auth/logout` hủy phiên. Register/login mật khẩu trả `410`; không dùng mã mời. OAuth/PKCE MCP dùng cùng user SQLite.
- `GET /api/v1/bots?limit=&cursor=` trả bot của chủ tối đa 50/trang. API create/edit/validate/simulate giữ kiểm tra chủ; edit sai revision trả `409`.
- `apps/api/src/admin-page.mjs`, `scripts/promote-admin.mjs`: `/admin`; `GET /api/admin/users`, `GET /api/admin/audit` phân trang tối đa 50; `POST /api/admin/users/{id}/{lock,unlock,revoke-sessions,cancel-queue}` đổi trạng thái/thu hồi phiên web và MCP/hủy lượt chờ, ghi audit. Player bị `403`. Chỉ lệnh server `node scripts/promote-admin.mjs --sub GOOGLE_SUB` mới cấp quyền admin sau khi Google account đã tạo; chọn DB bằng `PROMPTCHIEN_DB_PATH`.
- `apps/web/index.html`, `apps/web/src/api.ts`, `apps/web/src/main.ts`: Google login, bot cloud, version, báo conflict, nhập nháp local có xem trước/xác nhận/tránh trùng, thử bot cloud; queue local được ghi là thử.
- `vercel.json`, `.vercelignore`, `.gitignore`: web proxy `/api/*` và `/admin` đến API VPS để cookie phiên là cùng origin; không đưa `.env` hoặc Google client JSON lên Vercel/Git. `apps/web/src/main.ts` bật FedCM cho nút Google trong trình duyệt chặn cookie bên thứ ba.
- `tests/m1-account.test.mjs`, `tests/api-queue.test.mjs`, `tools/smoke-auth.mjs`, `tools/m3-smoke.mjs`, `tools/m4-smoke.mjs`: test tích hợp bằng JWKS thử và SQLite tạm. `package.json`/`pnpm-lock.yaml` khai báo trực tiếp `jose` để xác minh token. `apps/api/.dev.vars.example` của Worker demo cũ đã bỏ.
