## Đã bàn giao

- Cloudflare Worker tại `apps/api` với D1 migration `0001_m3.sql` và Durable Object `MatchQueue` dùng SQLite để ghép FIFO hai tài khoản khác nhau.
- Tài khoản invite-only, session cookie, OAuth Authorization Code + S256 PKCE, metadata protected resource và dynamic client registration.
- Tám MCP tools: `get_rules`, `create_bot`, `get_bot`, `edit_bot`, `validate_bot`, `simulate_bot`, `get_replay`, `submit_bot`.
- Resources cho agent: `/agent.md`, `/rules`, `/schema/bot.json`, `/schema/replay.json`.
- API public cho Web Lab, API account/bot/replay có xác thực, idempotency key cho thao tác ghi, body/replay giới hạn 4 MiB.
- Vercel static build qua `vercel.json`; API base lấy từ `PROMPTCHIEN_API_BASE` lúc build.
- VPS chạy Node 22.23.2 + Nginx; service `promptchien-api` tự khởi động lại, SQLite ở `/opt/promptchien/data/promptchien.sqlite`.

## Bằng chứng local và VPS

```text
pnpm check

node tools/m3-smoke.mjs

# M3 LOAD PASSED: 10 concurrent simulations, p95=9140.0ms
```

VPS đo được 1 vCPU và 1,9 GiB RAM. Muốn đạt load gate hiện tại, nâng VPS lên tối thiểu 2 vCPU rồi chạy lại benchmark; không coi đây là cam kết hiệu năng trước khi đo lại.

## Việc còn lại

1. Nâng VPS và chạy lại `node tools/m3-load.mjs` để đóng load gate.
2. Kiểm tra luồng thật trên ChatGPT/Claude bằng endpoint HTTPS production.

Cloudflare Worker vẫn giữ làm phương án dự phòng; simulation trên Workers Free bị giới hạn CPU 10 ms/request. Không cần bật Workers Paid nếu dùng tuyến VPS.
