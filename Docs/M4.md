# M4 — Replay trong chat

**Tình trạng:** Đã triển khai trên VPS, hosted contract/fallback smoke pass; cần kiểm tra render cuối trên ChatGPT/Claude sau khi connector refresh.

## Đã làm

- Thêm tool `render_replay` với `_meta.ui.resourceUri` và `openai/outputTemplate`.
- Thêm resource `ui://promptchien/replay-viewer/v1.html` với MIME `text/html;profile=mcp-app`.
- Nhúng `@modelcontextprotocol/ext-apps` `2.0.0` trong widget.
- Widget dùng lại `packages/ui` (`viewCheckpoint`, `drawViewer`, `captionEvent`), có phát/tạm dừng, tua nhịp, tốc độ và damage heatmap.
- Payload lớn của replay đi trong `_meta["promptchien/replay"]`; kết quả text vẫn có metadata và link fallback.
- Fallback là link ký HMAC sống 24 giờ tới `/replays/{replay_id}` trên API; mở ngoài chat vẫn dùng cùng widget ở chế độ standalone.

## Kiểm tra

```powershell
pnpm check
$env:M4_API_URL="http://127.0.0.1:8787"; $env:M4_INVITE_CODE="local-demo-invite"; node tools/m4-smoke.mjs
$env:M4_API_URL="https://api.kythuatvang.com"; $env:M4_INVITE_CODE="<INVITE_CODE>"; node tools/m4-smoke.mjs
```

M4 smoke local và hosted đều kiểm tra negotiation, `resources/list`, `resources/read`, metadata tool, viewer payload, link fallback ký và HTML standalone. Hosted API đang chạy tại `https://api.kythuatvang.com`; `pnpm check` vẫn đạt 18/18 test M0–M3.

## Gate còn lại

Kết nối endpoint production bằng một host MCP Apps thật, gọi `render_replay`, rồi xác nhận canvas hiển thị và các nút play/pause/seek hoạt động. Host chỉ có tools phải mở được link `/replays/...?...share=...`.
